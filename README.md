# BERT Text Classification using DistilBERT

## Project Overview
This project performs text classification using Hugging Face DistilBERT model.

## Features
- Data preprocessing
- Model training
- Evaluation metrics
- Weights & Biases tracking
- Hugging Face model upload

## Files
- data.py → data preprocessing
- train.py → model training
- eval.py → evaluation
- utils.py → helper functions

## Tools Used
- Python
- Transformers
- PyTorch
- Weights & Biases
- Hugging Face
